# Kawaii Minimal — 产品视觉语言

日期：2026-08-29  
状态：产品界面当前视觉规范  
产品：汇报不返工  
相关：[`2026-08-29-动态证据模块-design.md`](./2026-08-29-动态证据模块-design.md)、[`2026-08-29-汇报不返工-milestones.md`](./2026-08-29-汇报不返工-milestones.md)

本文定义产品工作台（创建 / 确认主线 / 预览验收）的视觉与交互。目标不是堆叠可爱装饰，而是在清晰层级上点缀少量糖果色，让界面鼓励、放松、好用。

## 1. 定位

界面是一份「干净的文具桌」：创建、确认、预览都是贴在奶油白底上的色纸卡片。目标用户是需要认真完成汇报、同时希望情绪不被压住的人。

成功标准：

- 第一眼觉得明亮、轻盈，而不是职场模板或儿童贴纸墙
- 主路径（输入 → 确认 → 预览）信息层级不变，按钮和标签一眼能找到
- 糖果色只出现在按钮、标签、图标和小装饰；背景和大卡片保持低饱和
- 负面状态（错误、阻塞、删除）柔和，不制造额外压力
- 导出给领导的 PPT 可读、可编辑；不把手写标题或贴纸装饰带进职场稿件

## 2. 原则

1. **布局先于装饰。** 卡片结构极简，圆角和色点是点缀，不是主体。
2. **甜但不过度。** 画面中心留给内容；每屏装饰不超过 2–3 处色块。
3. **软塑料 / 贴纸感。** 大卡片像贴在白板上的色纸；按钮像软糖胶囊。纯色或轻微渐变，不用复杂纹理。
4. **轻、软、弹。** 反馈要被注意到，但不要紧张。
5. **两种场合两套克制。** 工作台可以可爱；PPT 只共用色板，不共用手写标题和贴纸。

## 3. 色板

工作台 CSS 变量在 `app/globals.css`；PPT 色值在 `lib/presentation/theme.ts`（无 `#`）。两边语义对齐。

| Token | Hex | 用途 |
| --- | --- | --- |
| `--bg` | `#FFF7F2` | 奶油白底 |
| `--title` / `--body` | `#5A4A62` | 标题与正文（紫灰，不是海军蓝） |
| `--primary` | `#8B7CC9` | 强调文字、进行中标签 |
| `--cta` / `--accent` | `#FF7EB3` | 主按钮、关键标签 |
| `--mint` | `#7ED9C0` | 次按钮、已完成步骤 |
| `--lemon` | `#FFE08A` | 选中芯片、小装饰 |
| `--lilac` | `#E8DEFF` | 未选步骤、次要底 |
| `--cream` | `#FFE6C7` | 暖色点缀底 |
| `--olive` | `#5C8F82` | 辅助说明（薄荷灰绿） |
| `--muted` | `#A898A4` | 弱化文字 |
| `--line` | `#F3DCE6` | 描边 |
| `--error` | `#C45C74` | 错误与阻塞（玫瑰，不是警报红） |
| `--error-bg` | `#FFE8EE` | 错误胶囊底 |

背景叠两层极淡渐变：左上淡粉、右下薄荷，中间保持奶油白。不要第三层高饱和光斑。

糖果色使用边界：

- **可以：** 主按钮渐变、步骤胶囊、芯片、小贴纸圆、幻灯片左侧细条
- **不可以：** 整页高饱和底、大面积粉紫渐变卡片、正文着色成糖果色

## 4. 材质与圆角

| 元素 | 圆角 | 表面 |
| --- | --- | --- |
| 页面卡片 `.panel` | 1.6rem | 白/奶油半透明，细粉描边，轻阴影 |
| 输入框 `.field` | 1.1rem | 近白实色，聚焦时柠檬色描边 |
| 按钮 / 芯片 / 步骤 | 999px | 胶囊；主按钮粉→玫红轻微渐变 |
| 幻灯片预览框 | 1.25rem | 白底贴纸，左侧 5px 糖果条 |
| 装饰色块 | 满圆或 2.5rem | 低不透明度粉 / 薄荷 / 柠檬 |

不做：玻璃拟态、噪点纹理、强内阴影、直角卡片。

## 5. 字体

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| 展示 | `ZCOOL XiaoWei`（`--font-display`） | 页面标题、kicker |
| 正文 | `Noto Sans SC`（`--font-body`） | 表单、说明、按钮、幻灯片预览正文 |
| PPT | `Microsoft YaHei` | 导出文件，保证 WPS / PowerPoint 中文不乱码 |

标题可以有手写/衬线亲近感；正文必须易读。不要把展示字体用在 textarea、表格和验收文案上。字号基准 18px，行高约 1.65。

## 6. 交互

时长 **220–280ms**。缓动：进入用 `cubic-bezier(0.34, 1.56, 0.64, 1)`（轻回弹）；离开用 `ease-out`。

| 对象 | Hover | Active | Disabled |
| --- | --- | --- | --- |
| 主/次按钮 | 上浮 3px + 放大约 1.04，阴影变暖 | 略压回 | 透明度 0.55，无位移 |
| 卡片 | 上浮 1–2px 或提亮 1–2%，不改布局结构 | — | — |
| 输入框 | — | 柠檬描边 | — |

`prefers-reduced-motion: reduce` 时关闭位移和回弹，只保留颜色变化。

不要：强震动、红色闪烁、长于 400ms 的装饰动画、页面进场连环弹跳。

## 7. 状态与氛围

- **错误 / 阻塞：** 玫瑰字 + 淡粉胶囊（`.notice-error`），不使用警报红、感叹三角轰炸。
- **成功 / 可提交：** 柠檬芯片（`.chip-on`），文案平静（「可提交」即可）。
- **进行中：** 粉色主按钮文案（「正在听」「正在分析」），不要换成灰色死按钮除非真的 disabled。
- **装饰：** `AppShell` 角上最多两块低饱和色纸（粉圆、薄荷圆角），外加一枚约 44px 的柠檬笑脸贴纸。不放吉祥物插画、不放满屏贴纸。

用户应感到：这是一个会让心情变好、但仍能认真把汇报做完的空间。

## 8. 落到本产品的页面

现有信息架构不变（创建 → 确认主线 → 预览验收）。只换皮肤与动效。

- **创建 / 确认：** 大贴纸卡片承载表单；步骤条用粉（当前）、薄荷（已完成）、淡紫（未到）。
- **预览：** 幻灯片框是贴纸；验收阻塞用玫瑰胶囊；「可提交」用柠檬/薄荷芯片。
- **Notion / 语音：** 嵌在淡紫浅底小卡片里，不另起一套颜色。

## 9. PPT 边界

`theme.ts` 与工作台共用奶油底、紫灰字、粉强调、薄荷与柠檬点缀。

明确不做：

- PPT 标题改手写字体
- 幻灯片上堆笑脸或贴纸
- 把职场结论页做成相册风

网页预览可以比 PPT 更圆、更甜；导出文件以领导可读为先。

## 10. 实现入口

| 文件 | 职责 |
| --- | --- |
| `app/globals.css` | Token、背景、按钮/卡片/芯片/错误、动效 |
| `app/layout.tsx` | 展示字体 + 正文字体 |
| `components/app-shell.tsx` | 页面装饰色块 |
| `lib/presentation/theme.ts` | PPT 色板 |

新增组件或页面必须复用 `.panel` / `.btn-primary` / `.btn-secondary` / `.field` / `.chip` / `.notice-error`，不要另写一套饱和色。
