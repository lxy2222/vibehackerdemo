日期：2026-08-29  
原则：**第一版只要求能跑。** 当前产品定义见 [`2026-08-29-动态证据模块-design.md`](./2026-08-29-动态证据模块-design.md)。视觉语言见 [`2026-08-29-kawaii-minimal-design.md`](./2026-08-29-kawaii-minimal-design.md)。

```text
M0  能下载 PPTX       ← 已完成
M1  数字来自表格       ← 已取消（被模版优先 / 对话主线取代）
M2  澄清到生成闭环     ← 已取消（被「确认主线」取代）
M3  自动验收           ← 已完成
M4  套设计风格         ← 产品界面：Kawaii Minimal
```

## M0 · 第一版：能跑起来

**状态：已完成（2026-08-29）**

本地 `npm run dev`，打开页面即可下载可编辑 PPTX。

**目标：** 本地打开页面，点一下，下载一份可编辑 PPTX。

做：

- 初始化 Next.js（App Router + TS + Tailwind）
- 色卡和中文字体写进主题常量（不追求成品视觉）
- 一份写死的 `DeckSpec` + PptxGenJS 渲染器
- 下载可编辑 PPTX

**验收：**

- `npm run dev` 能打开
- 下载的文件能用 WPS / PowerPoint 打开
- 中文不乱码，封面以外有演讲备注

## M1 · 数字是算出来的

**状态：已取消**

原计划从 CSV 算 Fact 再填 PPT。主路径改为对话/材料分析，不再要求上传表格或 Fact Engine 进产品主流程。解析器和 demo CSV 可留在仓库备查，不作为验收项。

---

## M2 · 闭环能跑（旧主路径）

**状态：已取消**

原计划：领导原话 → 最多 3 问澄清 → 大纲 → 生成 PPT。已被 M5a「确认主线」取代。旧澄清页重定向到确认页。

## M3 · 验收能跑

**状态：已完成（2026-08-29）**

**目标：** 下载前知道能不能交给领导，并复制交付消息。

做：

- 代码验收：页数、factRefs、时长、空文件、领导点名指标缺失则阻塞
- Pro 语义验收 + 交付消息
- 预览页：可提交 / 需要修改

**验收：**

- 完整 demo：能给出交付消息
- 领导点名要看转化、材料没有数字：出现阻塞
- 只缺量化、领导没点名具体指标：「缺量化」是建议不是阻塞

---

## M4 · 套设计风格

**状态：产品界面已按 Kawaii Minimal 落地（2026-08-29）**  
**依据：** [`2026-08-29-kawaii-minimal-design.md`](./2026-08-29-kawaii-minimal-design.md)

**目标：** 工作台看起来干净、甜、好用；不把可爱装饰带进给领导的 PPT 正文。

做：

- 奶油白 + 淡粉/薄荷背景，糖果色只用于按钮、标签、小装饰
- 大圆角贴纸卡片、软糖胶囊按钮、轻回弹 hover（220–280ms）
- 展示字体用于页面标题；正文与 PPT 保持易读无衬线
- 错误/阻塞用玫瑰胶囊，不用警报红

不做：PPT 手写标题、幻灯片贴纸墙、改主路径或验收逻辑。

**验收：**

- 创建 / 确认 / 预览三页共用同一套 token 与动效
- 主按钮、步骤条、芯片能看出粉 / 薄荷 / 柠檬分工
- 导出 PPT 仍可用 WPS / PowerPoint 打开，中文不乱码

## M5a · 对话能分析

**状态：已完成（2026-08-29）**  
**依据：** [`2026-08-29-动态证据模块-design.md`](./2026-08-29-动态证据模块-design.md)

**目标：** 发送一段对话后，系统能指出领导要判断的问题、风险点和下一步，用户能改主线再跑一遍。

做：

- 创建页：「我最初的汇报背景」（可打字或语音）+ 工作对话/材料。无漏斗、无必填进度
- `ReportAnalysis`：`title`、`leaderQuestion`、`intent`、`coreConclusion`、`keyFindings`、`risks`、`nextActions`、`decisionAsk`、`missingInformation`
- Flash 分析；确认页可编辑后重新分析
- 用文字页（结论 / 风险 / 行动）出预览

**验收：**

- 粘贴或口述一段工作沟通，大约一分钟内回到「确认主线」
- 能看到核心问题、风险点、下一步；数字不编造
- 改一句结论或补一句材料，能重新分析

## M5b · 连接 Notion

**状态：已完成（2026-08-29）**  
**依据：** [`2026-08-29-动态证据模块-design.md`](./2026-08-29-动态证据模块-design.md)

**目标：** 用户连上 Notion 后，能选页面，把正文拉进「工作对话或材料」，再走现有分析。只读不写回。

做：

- 创建页和确认页「连接你的 Notion」
- 点「去授权」跳转 Notion OAuth，勾选要分享的页面
- 回来列出可访问页面，勾选后导入正文
- Token 只放 httpOnly cookie

**验收：**

- 不连 Notion 时，纯粘贴路径和 M5a 一样能用
- 点「去授权」能打开 Notion 授权；成功后能选页面并导入
- 导入文本带页面标题和链接来源
- Key / token 只在服务端

**状态：已取消，不做**
